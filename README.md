## 🎯 عن التطبيق

**Kitabi** تطبيق أندرويد تعليمي موجّه لطلاب ليبيا في المراحل:
- الابتدائية
- الإعدادية
- الثانوية

يهدف إلى توفير تجربة تعليمية شاملة ومجانية بالكامل.

---

## ✨ المميزات

### الإصدار 0.1 (الحالي - تجريبي)
- 📚 مكتبة الكتب (12 صف دراسي)
- 📄 عرض كتب PDF (أونلاين + أوفلاين)
- 👤 حساب طالب (اسم + صف + مراقبة)
- 🔔 إشعارات
- 🌙 وضع ليلي / نهاري
- 🎛️ غرفة تحكم للمشرف

### الإصدارات القادمة
- 🤖 معلم AI (يعتمد على المنهج الليبي)
- 📝 اختبارات مولدة
- 📊 متابعة المستوى
- 💬 منتدى تفاعلي
- 🏆 إنجازات ولوحة شرف
